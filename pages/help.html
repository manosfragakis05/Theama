Setup & Help

Start with a free account, set up your add-ons, and play your first stream. Connecting TorBox in Theama is optional.

Start here

Your first three steps

Theama is a player. You bring the media through compatible add-ons. A free Theama account is recommended: it is optional, but most features need one.

  1. 01

    Create a free Theama account

    Sign up in Settings to save your app library, track watch progress, use the release calendar, and keep your lists and friends. You can browse and play compatible add-on streams as a guest.

  2. 02

    Add a stream provider

    Configure a compatible stream add-on, then install its manifest URL. If it needs a TorBox key, you can enter it in the add-on’s setup instead of in Theama.

  3. 03

    Find something to watch

    Open Discover, choose a title, and select a playable source. No TorBox key is required in Theama for compatible add-on streams. Sign in to save recognised titles and track playback in Theama.

Install Theama

Add Theama to your home screen or app launcher so you can open it like an app, with its own window.

iPhone & iPad Safari
  1. Open Theama in Safari. If you opened it inside another app, copy the address into Safari first.
  2. Open the Share menu, then choose Add to Home Screen. You may need to scroll through the actions.
  3. If shown, leave Open as Web App enabled, then tap Add.
  4. Launch Theama using its new home-screen icon.

If the action is missing, use Edit Actions in the share menu. You may need to sign in again or restore your add-ons in the installed app.

Android Chrome
  1. Open Theama in Chrome.
  2. Open the three-dot menu and look for Install or Add to Home screen. Some versions put this under Install and create shortcut.
  3. Confirm installation, then open Theama from your home screen or app drawer.

Computer Chrome, Edge & Safari

Chrome: use the install icon in the address bar, or open the menu → Cast, save, and share → Install page as app.

Edge: use the install icon, or look under the menu → More tools → Apps → Install this site as an app.

Safari on Mac: choose File → Add to Dock, or find Add to Dock in the Share menu on supported macOS versions.

If installation is unavailable, you can keep using Theama in your browser.

Connect TorBox (optional)

You do not need to enter a TorBox API key in Theama to play compatible add-on streams. An add-on can use the key configured in its own setup and supply playable sources to Theama.

Connect TorBox in Theama if you want to see and organise the files already in your TorBox cloud library. They appear under Library → Cloud. This connection is separate from your free Theama account.

To connect your cloud library

  1. Go to Settings → Integrations and select Pair with TorBox.
  2. Choose Open TorBox pairing page and enter the temporary code if it isn’t already filled in.
  3. Sign in to TorBox and finish approving access. Keep Theama open in its original tab or app window.
  4. Return to Theama. It checks for approval automatically and shows Connected when pairing finishes.

You can enter the code at tor.box/link on another device. If it expires, choose Generate new code and use the latest one.

Prefer manual setup? Expand Use an API key instead in the TorBox card. To remove the connection later, choose Disconnect TorBox.

Install an add-on

Catalog add-ons help you browse. Stream add-ons provide sources to play. The included TMDB catalog provides title information; it doesn’t supply streams.

If your stream add-on uses TorBox, enter your key on the add-on’s configuration page when requested, then install the generated manifest URL. You can leave Theama’s own TorBox connection empty and still play the add-on’s compatible sources.

Important

HTML add-ons are not supported yet. Use a compatible Stremio add-on with a JSON manifest URL ending in /manifest.json. Add-ons that rely on an embedded website or HTML video page are not currently supported.

An add-on may have a website for configuration. Finish setup there, then copy its manifest URL into Theama.

Where to find add-ons

Look for developer announcements and setup discussions in r/StremioAddons. The Stremio add-on guide also explains how to browse its Official and Community catalogs in Stremio.

Once you find an add-on, visit its developer’s page, check its requirements, and copy the generated manifest URL. Stremio install buttons don’t install add-ons into Theama automatically.

These are third-party resources, and a listing does not guarantee compatibility with Theama. Use add-ons you trust and only access content you’re authorized to watch.

  1. Get a compatible add-on’s manifest URL, usually ending in /manifest.json. Complete any configuration on the provider’s site first.
  2. In Settings → Scrapers & Add-ons, select + Add New Add-On.
  3. Paste the URL, choose Install Add-on, and wait for it to appear under Installed Add-ons.
  4. Open Discover to browse its catalogs or select a title to check its stream results.

Sign in to your Theama account to save recognised titles from add-on playback to your app library and track watch progress in the built-in player. This does not require a TorBox key in Theama.

Add friends & share your profile

Friends in Theama are people you follow. Connect through a shared profile link.

  1. Sign in to a Theama account in Settings. This is separate from your TorBox account.
  2. Open Profile and tap the Share Profile icon beside Settings. Send or copy your profile link using the share menu.
  3. Ask a friend to share their profile link. Open it and choose Follow on their profile.
  4. Find them under Following in the desktop sidebar, or My Friends on your own Profile on mobile.

Open a friend’s profile to see their public watchlists. Following is one-way: your friend can follow you back using your link. Private lists stay off your public profile.

Keep watchlists & favourites

Open a movie or series, then use its save/watchlist button to add it to Favourites or one of your lists. Find your saved titles in Profile.

For a custom list, sign in, open Profile → New List, give it a name, and choose its privacy. Public lists can appear on your shared profile; private lists are for you.

Guest favourites stay in this browser. Sign in to keep your profile and lists available across devices.

Playback, your library & queues

Compatible add-on streams play without a TorBox key in Theama. Sign in to a free Theama account to save recognised titles in your app library and track watch progress in the built-in player.

Library → Library contains your saved titles. Library → Cloud is optional: connect TorBox to browse and organise your existing cloud files. On a cloud poster with a TMDB match, use the plus icon to add it to your app library.

When a saved series has multiple torrents, the episode picker merges them. If episodes overlap, All torrents (merged) keeps the most recently added copy of each episode. Use the torrent dropdown to choose an individual source.

During playback, use Queue to see upcoming items, select another item, remove an entry, or shuffle. Clearing the queue removes its entries; it doesn’t delete your TorBox files.

The Internal player plays inside Theama. You can choose a different default under Settings → Default Player. External players need to be installed on your device, and supported options depend on your platform.

Important

Some devices can’t play every video link in the built-in player. Supported video formats, audio formats, and streaming methods vary by device and browser.

If videos repeatedly fail to start, stop during playback, or have no picture or sound, you may need an external player. Install a supported player on your device, then select it under Settings → Default Player.

An external player can help with format compatibility. An unavailable source or a network problem may still require another link.

Your account & saved settings

Create a free Theama account in Settings as your first step. It is optional for browsing and compatible add-on playback, but most features require you to sign in: your saved app library, watch tracking, release calendar, profile sharing, following friends, and custom watchlists.

A Theama account and a TorBox account are separate. Add-on playback can be saved and tracked when you are signed in to Theama, even when its TorBox connection is empty. Track watch progress for recognised titles using the built-in player.

When something needs a nudge

Do I need a TorBox API key in Theama?

No. A compatible add-on can use the key from its own configuration and provide a playable stream. Theama’s TorBox connection is optional and lets you browse and organise your existing cloud library. Sign in to a free Theama account to save recognised titles and track watch progress in the built-in player.

I can browse titles, but there are no streams

Check that you installed an add-on that provides streams. TMDB only supplies catalog information. Try another title and check your add-on’s configuration, including any provider key it requires. A TorBox connection in Theama is not required for compatible add-on streams. A magnet or hash-only source needs a connected torrent service; choose a playable add-on source if you do not want to connect one.

I can play streams, but my library or progress is missing

Sign in to your Theama account to save your app library and track recognised titles in the built-in player. Guest playback is not saved to an account. The Cloud tab is separate and only shows your existing TorBox files after you connect TorBox in Theama.

TorBox accepted my code, but Theama is still waiting

Finish signing in and approving access on the TorBox page, then return to the original Theama tab. Entering the code is only part of approval. Keep that tab open while it checks. If the code expires or an error appears, generate a new code and complete approval again.

I can’t find the install option

Open Theama in your device’s main browser instead of an in-app browser. Check the installation steps above for your device. If you already installed it, look for its icon on your home screen or app launcher. You can also use Theama directly in the browser.

My friend’s lists are missing

Only public lists appear on a shared profile. Ask your friend to check the list’s privacy. To follow someone, sign in to your Theama account and open their profile link.

My settings disappeared on another device

Sign in to the same Theama account and check the API-key and add-on sync options. Local settings belong to the browser or app where you saved them. Clearing browser data can remove local settings and guest favourites.

Playback buffers, fails, or has no audio

Check your connection and try a different source or a smaller file. For an add-on source, check its provider configuration and source availability; for a connected TorBox cloud file, check that it is ready in TorBox. For a format your device struggles with, try an installed external player from Settings.

Still need a hand?

When reporting a problem, include your device, browser, and what you were doing. Leave out API keys and private add-on URLs.
